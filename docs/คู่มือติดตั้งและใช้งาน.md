# คู่มือติดตั้งและใช้งาน — iT Phone Planet LINE Bot

เอกสารนี้สำหรับ **ลูกค้า / ผู้ติดตั้ง**  
รันบนเครื่องตัวเองด้วย **XAMPP (PHP + MySQL)** ได้เลย **ยังไม่ต้อง deploy ขึ้นเซิร์ฟเวอร์**

> หมายเหตุสำคัญ  
> บอท LINE ใช้งานได้เมื่อเครื่องที่รัน XAMPP **เปิดอยู่** และมี **Tunnel (Cloudflare/ngrok)** ชี้ webhook  
> ปิดเครื่อง / ไม่เปิด tunnel = LINE เรียกบอทไม่ได้ชั่วคราว (ปกติของโหมดทดสอบบนเครื่อง)

---

## สิ่งที่ได้ในโปรเจกต์นี้

1. เข้าสู่ระบบ / สมัครสมาชิก (ต้องทำก่อนสั่งซื้อ)
2. เลือกสินค้า สั่งซื้อ กรอกที่อยู่ โอนเงิน แนบสลิป
3. อัปเดตสถานะเป็น “ชำระเงินแล้ว” หลังส่งสลิป
4. ดูประวัติออเดอร์ / บัญชีของตัวเองเท่านั้น (ลิงก์เซ็นลายเซ็น)
5. หน้าแอดมิน: สินค้า ออเดอร์ ตรวจสลิป ใส่เลขพัสดุ

Repo: https://github.com/thinnakorn-sun/it-phone-planet-bot

---

## สิ่งที่ต้องเตรียม

| รายการ | รายละเอียด |
|---|---|
| คอมพิวเตอร์ | macOS / Windows |
| XAMPP | Apache + MySQL + PHP 8.0 ขึ้นไป |
| Git | สำหรับ clone จาก GitHub |
| Cloudflare Tunnel หรือ ngrok | ให้ LINE ยิง webhook เข้าเครื่องได้ |
| LINE Official Account | Messaging API เปิดแล้ว |
| คีย์ LINE | Channel secret + Channel access token (Long-lived) |

## ขั้นตอนติดตั้ง (ครั้งแรก)

### 1) เปิด XAMPP

เปิด **Apache** และ **MySQL**

### 2) ดาวน์โหลดโค้ด

```bash
cd /Applications/XAMPP/xamppfiles/htdocs
git clone https://github.com/thinnakorn-sun/it-phone-planet-bot.git
cd it-phone-planet-bot
```

Windows ตัวอย่าง path: `C:\xampp\htdocs\it-phone-planet-bot`

หรือ clone ไว้โฟลเดอร์อื่น แล้วใช้สคริปต์ sync (macOS):

```bash
bash scripts/sync-to-xampp.sh
```

### 3) สร้างไฟล์ `.env`

```bash
cp .env.example .env
```

แก้ไขค่าสำคัญ:

```env
APP_URL=http://localhost/it-phone-planet-bot/apps/web
ADMIN_URL=http://localhost/it-phone-planet-bot/apps/admin
ASSET_URL=http://localhost/it-phone-planet-bot/apps/web/assets
PUBLIC_BASE_URL=

DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=it_phone_planet
DB_USER=root
DB_PASS=

LINE_CHANNEL_SECRET=ใส่จาก LINE Developers
LINE_CHANNEL_ACCESS_TOKEN=ใส่จาก LINE Developers

ADMIN_USERNAME=admin
ADMIN_PASSWORD=รหัสที่ต้องการ

PAYMENT_BANK_NAME=ธนาคารกสิกรไทย
PAYMENT_ACCOUNT_NAME=iT Phone Planet
PAYMENT_ACCOUNT_NUMBER=เลขบัญชีจริง
PAYMENT_NOTE=โอนแล้วแนบสลิปในแชทนี้ได้เลยค่ะ
```

- อย่า commit ไฟล์ `.env` ขึ้น GitHub  
- `PUBLIC_BASE_URL` ใส่ทีหลังเมื่อเปิด tunnel แล้ว (ดูด้านล่าง)

### 4) Import ฐานข้อมูล (phpMyAdmin)

เปิด `http://localhost/phpmyadmin` แล้ว import ตามลำดับ:

1. `database/schema.sql` (สร้าง DB + ตาราง รวมระบบสมาชิก)
2. `database/seed.sql` (สินค้าตัวอย่าง / FAQ)

ถ้าเคย import schema เก่าไปแล้ว (ก่อนมีระบบสมาชิก) ให้รันเพิ่ม:

- `database/alter_customers_auth.sql`
- `database/alter_orders_payment_method.sql` (ถ้ายังไม่มีคอลัมน์วิธีชำระ)
- `database/update_products.sql` (ถ้าต้องการอัปเดตรายการสินค้า)

### 5) สร้างแอดมิน

เปิด:

`http://localhost/it-phone-planet-bot/apps/web/install.php`

จากนั้นเข้าแอดมิน:

`http://localhost/it-phone-planet-bot/apps/admin/login.php`

### 6) เช็กว่าระบบขึ้น

`http://localhost/it-phone-planet-bot/apps/web/health.php`

ควรเห็น `"ok": true` และ `"database": true`

## เชื่อม LINE (จำเป็นถ้าจะทดสอบบอทจริง)

คู่มือย่อ — รายละเอียดเพิ่มใน `docs/LINE-SETUP.md`

### 1) เปิด Tunnel

```bash
cloudflared tunnel --url http://127.0.0.1:80
```

ได้ URL ประมาณ:

`https://xxxxx.trycloudflare.com`

### 2) อัปเดต `.env`

```env
PUBLIC_BASE_URL=https://xxxxx.trycloudflare.com/it-phone-planet-bot/apps/web
```

แล้ว sync (macOS):

```bash
bash scripts/sync-to-xampp.sh
```

### 3) ตั้ง Webhook ใน LINE Developers

```text
https://xxxxx.trycloudflare.com/it-phone-planet-bot/apps/web/webhook.php
```

- เปิด **Use webhook**
- กด **Verify**
- ปิด Auto-reply / Greeting ของ LINE OA ที่ชนกับบอท

> Tunnel ฟรี (trycloudflare) เปลี่ยนโดเมนได้ทุกครั้งที่เปิดใหม่  
> เปิดใหม่แล้วต้องอัปเดต `PUBLIC_BASE_URL` + Webhook URL ใหม่ทุกครั้ง

## วิธีทดสอบใช้งาน (ลูกค้าใน LINE)

1. เพิ่มเพื่อน OA / ทักบอท
2. พิมพ์ `สวัสดี` หรือ `เมนู`
3. กด **สมัครสมาชิก** หรือ **เข้าสู่ระบบ** (ขั้นตอนแรกก่อนสั่งซื้อ)
4. กด **เลือกซื้อสินค้า** → เลือกหมวด → สั่งซื้อ
5. กรอกชื่อ เบอร์ ที่อยู่ → โอนเงิน → ส่งรูปสลิปในแชท
6. สถานะจะเป็น **ชำระเงินแล้ว** และมีข้อความขั้นตอนถัดไป
7. พิมพ์ `สถานะ` / `ประวัติการสั่งซื้อ` / `บัญชีของฉัน` เพื่อดูของตัวเอง

### คำสั่งที่ใช้บ่อย

| พิมพ์ | ความหมาย |
|---|---|
| สวัสดี / เมนู | หน้าเข้าสู่ระบบ / สมัคร / เลือกซื้อ |
| เลือกซื้อสินค้า | เปิดหมวดสินค้า (ต้องล็อกอินแล้ว) |
| สถานะ | ออเดอร์ล่าสุด + ลิงก์ประวัติ |
| แจ้งชำระเงิน | เตรียมรับสลิป |
| แอดมิน | ส่งต่อพนักงาน |

### แอดมิน

- ออเดอร์ / สลิป / เลขพัสดุ: `apps/admin`
- หลังรับสลิป สถานะเป็นชำระเงินแล้ว → ระบบ**ตัดสต็อกอัตโนมัติ** → แอดมินใส่เลขพัสดุได้เลย
- ดูคงเหลือสินค้า: แดชบอร์ด (เรียงเหลือน้อย) หรือเมนู **สินค้า** คอลัมน์สต็อก / แก้ไขเพื่อปรับจำนวน
- ถ้าปฏิเสธสลิป ระบบจะคืนสต็อกให้

## ส่งมอบ / รันบนเครื่องลูกค้าโดยไม่ต้อง deploy

1. ลูกค้า clone จาก GitHub
2. ติดตั้งตามคู่มือนี้บน XAMPP ของลูกค้า
3. ลูกค้าใส่คีย์ LINE ของตัวเองใน `.env`
4. เปิด Apache + MySQL + Tunnel ตอนสาธิต

**ไม่จำเป็นต้องขึ้น Alwaysdata / Render ก่อนส่งงาน**  
โฮสต์คลาวด์ทำทีหลังได้เมื่อต้องการให้บอทออนไลน์ตลอดโดยไม่พึ่งเครื่องใคร

## แก้ปัญหาเร็วๆ

| อาการ | ตรวจ |
|---|---|
| LINE Verify ไม่ผ่าน / invalid host | Tunnel ตายหรือโดเมนเปลี่ยน → เปิดใหม่แล้วอัปเดต Webhook |
| ส่งสลิปแล้วเงียบ | ดู `storage/logs/app.log` และสิทธิ์โฟลเดอร์ `storage/slips` ต้องเขียนได้ |
| สั่งซื้อไม่ได้ เด้งให้ล็อกอิน | ปกติ — ต้องสมัคร/เข้าสู่ระบบก่อน |
| รูปสินค้าใน LINE ไม่ขึ้น | ตั้ง `PUBLIC_BASE_URL` ให้เป็น URL tunnel แล้ว sync |
| แอดมินเข้าไม่ได้ | รัน `install.php` อีกครั้ง หรือเช็ค `ADMIN_USERNAME` / `ADMIN_PASSWORD` ใน `.env` |
